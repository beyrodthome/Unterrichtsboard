# Unterrichtsboard

Übersichtsseite für Lehrkräfte zum Zeigen per Beamer/Apple TV: Timer, Stundenfahrplan mit Aufgabe pro Phase, Sozialform, Lautstärkeampel, iPad-Nutzung (inkl. „Wo liegt das iPad?“), KI-Nutzung mit AI-Badge-Stufen und Reflexion am Stundenende.

Läuft im Browser und lässt sich als App auf dem Home-Bildschirm installieren (funktioniert danach auch offline).
